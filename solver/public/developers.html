Solver.ca API

Connect Solver.ca to n8n, Zapier, Make, your website, form tools, RingCentral, Google Sheets, or your own scripts. Admins set up keys, webhooks and lead links under Integrations in the app.

Solver.ca never texts, emails or calls anyone by itself. Webhooks only tell your tools what changed. If a tool you connect sends messages, it must follow the house rules: never message Junk/Unqualified, referred, opted-out or “(copy)” leads.

1. Incoming lead links (no code)

Create one under Integrations → Incoming lead links, pick the board (and group), and paste the link into your form tool's “webhook” or “HTTP POST” step. Send JSON or form fields. Any field whose name matches a column title (for example Phone, Email, Province) fills that column. Everything else is added to the item's first update.

curl -X POST https://YOUR-SITE/api/v1/in/LINK-TOKEN \
  -H "Content-Type: application/json" \
  -d '{"first_name":"Dana","last_name":"Smith","Phone":"4035550101","Email":"dana@example.com","Amount Requested":85000}'

If “skip duplicates” is on, a second lead with the same phone number isn't created; the reply says "duplicate": true.

2. The API

Create a key under Integrations → API keys and send it with every request:

Authorization: Bearer ks_…
RequestWhat it does
GET /api/v1/boardsEvery board with its groups, columns and status labels.
GET /api/v1/boards/{board}One board. {board} can be the Solver.ca id, the Monday id, or the board name.
GET /api/v1/boards/{board}/itemsItems, newest change first. Filters: ?group=, ?updated_since=2026-11-09T00:00:00Z, ?limit= (max 500), ?offset=.
GET /api/v1/boards/{board}/items/{id}One item with its updates and subitems.
POST /api/v1/boards/{board}/itemsCreate an item: {"name", "group", "fields": {"Column title": value}, "update": "first note"}. The board's automations run, as in the app.
PATCH /api/v1/boards/{board}/items/{id}Change name, group or fields. Status changes and group moves run the board's automations.
POST /api/v1/boards/{board}/items/{id}/updatesPost an update: {"text": "…", "author": "RingCentral"}.
DELETE /api/v1/boards/{board}/items/{id}Delete an item (write keys only).
GET /api/v1/search?phone=4035550101Find leads on every board by phone (last 10 digits), ?email=, or name ?q=.

Fields can use the column's title ("Status") or its id ("color_mkp75dsm"). Status values use the label's name ("NA 1"). Dates are YYYY-MM-DD. Calculated columns (formulas, buttons) can't be set.

# move a lead to "Appointment Booked" and set its status
curl -X PATCH https://YOUR-SITE/api/v1/boards/Setter%20Desk%20(Jan)/items/ITEM_ID \
  -H "Authorization: Bearer ks_…" -H "Content-Type: application/json" \
  -d '{"group":"Appointment Booked","fields":{"Status":"Contacted"}}'

3. Outgoing webhooks

Add one under Integrations → Outgoing webhooks. Solver.ca sends a POST with JSON within a second of the change, and retries up to 3 times if your tool doesn't answer.

EventWhenExtra data
item.createdA new item, from the app, the API, an automation or a lead link
item.updatedAny column or the name changedchanges: [{column, from, to}]
item.status_changedA status column changedchange: {column, from, to}
item.movedMoved to another groupchange: {from, to}
update.createdSomeone posted an updateupdate: {text, at, byName}
item.deletedAn item was deleted
reminder.dueA “when date arrives” rule is due (follow-up day, appraisal day, renewal reminders…), at the time Monday usedreminder: {rule, column, date, notify}
{
  "event": "item.status_changed",
  "at": "2026-11-09T22:41:07Z",
  "board": { "id": "m18432603444", "name": "Setter Desk (Jan)" },
  "item": { "id": "…", "name": "Dana", "group": { "name": "New Uncontacted" },
            "fields": { "Status": "NA 1", "Phone": "4035550101" } },
  "change": { "column": "Status", "from": "Uncontacted", "to": "NA 1" }
}

Checking it's really Solver.ca

Each request has X-Solver-Signature: sha256=…, an HMAC-SHA256 of the raw body using the secret shown when you created the webhook. Bulk copies from Monday don't send webhooks.

Recipes

  • n8n: a Webhook node receives Solver.ca events; an HTTP Request node with your key creates or updates items.
  • Zapier / Make: “Webhooks by Zapier → Catch Hook” for events, “POST” to a lead link or the API to create leads.
  • RingCentral or Twilio: look up the caller with /api/v1/search?phone=, then post the call note with …/updates.
  • Google Sheets: an outgoing webhook on item.created into a Zap or n8n flow that appends a row.

# Keystone CRM — test build

An in-house, Monday-style CRM used to test a replacement before moving anything off Monday.

- Workspace sidebar with folders and board search; shows who is signed in and their role
- Boards, groups, items and typed columns (status with Monday's labels and colours, person, date,
  phone, email, number / money / percent, text). Formula, mirror and other computed columns come
  over as read-only snapshots.
- Main table (Monday-style grouped tables, colour bars, group summaries, 50 rows per group with
  "show more", subitems) and Kanban with drag-and-drop between status lanes
- Person filter, search, item drawer with updates, subitems and an activity log
- Board automations: "when status changes to X, move to group / set another status"

## Monday import

`import/` (git-ignored, it holds real client data) is generated by a read-only export of the
"MortgageSolver CRM" workspace and published alongside the page. The artifact owner sees an
"Import from Monday" button that copies it into the page's shared database (resumable).
Nothing is ever written back to Monday, and nothing here sends texts or emails.

# Keystone CRM — test build

A small, Monday-style CRM used to try out an in-house replacement before moving anything off Monday.

- Boards, groups, items, and typed columns (status, person, date, phone, email, number/money, text)
- Table view with group summaries, Kanban view with drag-and-drop between status lanes
- Item drawer with updates (comments) and an activity log
- Board automations: "when status changes to X, move to group / set another status"

All data is **sample data**. Nothing here reads from or writes to Monday, and nothing sends texts or emails.

Published as a claude.ai artifact (shared database through the artifact `db` capability):
